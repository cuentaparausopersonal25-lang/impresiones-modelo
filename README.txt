IMPRESIONES MODELO
Proyecto Flask preparado para probar y publicar.

En Windows:
1. Abrí CMD dentro de esta carpeta.
2. Ejecutá: py -m pip install -r requirements.txt
3. Ejecutá: py app.py
4. Abrí http://127.0.0.1:5000

En Render:
Build Command: pip install -r requirements.txt
Start Command: gunicorn app:app

Subí todos los archivos y carpetas del ZIP al repositorio.
